# v6ファイルシステムダンプツール

## 使用方法
```bash
$ ./dump
./dump type[oslbid] [, arg1 [, arg2]]
 o: print disk layout
 s: print superblock
 l: print log block
 b: print bitmap
 i: print inode, arg1: 開始inum[. arg2: 終了inum[=開始inum]]
 d: print data, arg1: 開始セクタ番号, [arg2: セクタ数[=1]]
```
