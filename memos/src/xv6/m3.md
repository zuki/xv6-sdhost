# Silicon Macで実行

## 必要なツールのインストール

- Homebrewでaarch64-elf-gcc, aarch64-elf-binutils, aarch64-elf-gdb,
  qemu, util-linux (sfdisk) をinstall
- muslをソースからコンパイル
- Homebrew caskでbalenaEtcherをinstall

## コンパイル環境の変更

- $(HOME)の変更によるmuslのインストールディレクトリの変更

```bash
$ git diff --name-only 0d8a8e7 50b2f19

```

- 引数の型チェックの厳密化によるエラーの修正
