# raspi3b+のペリフェラルの接続状況

```bash
[ BCM2837B0 SoC ]
   │
   ├── (USB 2.0 バス ×1本のみ) ── [ LAN7515 (ハブ/LAN) ] ─── 4× USB 2.0 ポート
   │                                                    　　　└─── 1× Gigabit Ethernet (最大~330Mbps)
   ├── (SDIO バス) ─────────── [ Wi-Fi ]
   ├── (PL011 UART) ────────── [ Bluetooth 4.2 ]
   ├── (Arasan SDIO) ────────── [ microSD カードスロット ]
   ├── (MIPI CSI / DSI) ─────── [ カメラ / ディスプレイ端子 ]
   └── (ダイレクト I/O) ──────── [ 40ピン GPIO ヘッダー ]
```

1. USB・ネットワーク系の接続状況（最重要のボトルネック）

SoCからは、USB 2.0ホストコントローラの「1ポート分」の信号だけが外に伸びています。それが基板上のLAN/USB統合コントローラIC（Microchip LAN7515）に接続され、そこから各ポートへと分岐しています。

    - 4基のUSB 2.0ポート: 全てLAN7515（USBハブ機能）を介して、SoCと1本のUSB 2.0バスで接続されています。
    - 有線LANポート（Ethernet）: 3B+で「ギガビットイーサネット」に対応しましたが、内部的にはLAN7515内部の「USB-LAN変換機能」を経由しています。そのため、USB 2.0の帯域制限を受け、物理上限速度は約300〜330 Mbpsに制限されます。

2. ワイヤレス通信（Wi-Fi / Bluetooth）の接続状況

ワイヤレスモジュール（Cypress CYW43455）は、USBとは別の独立した専用インターフェースでSoCと直結されているため、USBの帯域を圧迫しません。

    - Wi-Fi（11ac対応）: SoCのSDIOバスを介して接続されています。
    - Bluetooth 4.2: SoCの内部高精度UART（PL011 UART）に接続されています。

3. ストレージ・外部拡張（SD・GPIO）の接続状況

- microSDカードスロット: SoCのもう一つのSDカードコントローラ（一般的にArasan SDHCI）に直結されています。
- 40ピン GPIOヘッダー: SoCのI/Oピンからダイレクトに配線されています。内部のペリフェラル（SPI×2、I2C×2、UART×2、PWM×2など）を代替機能（Alt機能）としてマッピングして使用します。

※Bluetoothに高性能なPL011 UARTが割り当てられているため、GPIOピン（14/15番）のデフォルトUARTはクロック変動の影響を受けやすい「Mini UART」になっています。

4. ディスプレイ・カメラ（映像・音声）の接続状況

- HDMIポート: SoC内のGPU（VideoCore IV）コアからダイレクトにデジタル出力されます。
- CSI（カメラ）/ DSI（ディスプレイ）ポート: SoCと専用の高速シリアルバスであるMIPI規格（CSI-2 / DSI）で直結されています。
- 3.5mm AVジャック（音声・コンポジットビデオ）:音声はSoCのPWM信号をアナログフィルタに通して出力しています。ビデオ（コンポジット）はSoC内のVEC（Video Encoder）からアナログ出力されています。
